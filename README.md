# Orologio Magico

Una web app interattiva per aiutare i bambini a imparare a leggere l'orologio analogico e a collegare lo scorrere delle ore ai diversi momenti della giornata.

## Caratteristiche

- Quadrante interattivo con lancette facili da spostare tramite touch o mouse.
- Indicazione chiara tra giorno e notte (AM/PM).
- Associazione tra gli orari e le attività quotidiane.
- Nessuna dipendenza esterna: l'intera applicazione è contenuta nel file `index.html`.
- Salvataggio automatico delle impostazioni nella memoria del browser.

## Utilizzo

Una volta attivato GitHub Pages, l'app è disponibile all'indirizzo:

https://clouz.github.io/Orologio-Magico/

Per usarla a schermo intero su smartphone o tablet:

1. Apri il link dal browser (Chrome su Android o Safari su iPhone/iPad).
2. Apri il menu del browser e tocca **Aggiungi a schermata Home**.
3. Avvia l'app direttamente dall'icona creata sul dispositivo.

## Struttura del repository

- `index.html`: applicazione completa (HTML, CSS e JavaScript).
- `README.md`: documentazione del progetto.

## Modifiche

Per aggiornare testi o attività, modifica direttamente il file `index.html` su GitHub: ogni salvataggio sul branch `main` aggiornerà automaticamente la versione online.
